# act-policy

Capability policy decision core (PDP) for the [ACT](https://actcore.dev) toolchain.

> **`0.0.0` is a placeholder release** that reserves the crate name. The
> decision engine — `resolve` (effective ceiling) and `classify`
> (per-operation `Allow` / `Deny` / `Ask`) — lands in a later version.

Part of the [`act-cli`](https://github.com/actcore/act-cli) workspace.
